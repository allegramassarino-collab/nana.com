# Immagini prodotto

Questa cartella è pronta per le tue foto reali (es. quelle già presenti sul profilo Instagram @nanaenjoycolors).

Al momento le card prodotto usano un'icona SVG di un anello su sfondo colorato al posto della foto, così il sito è già completo e online. Per sostituirle con foto vere:

1. Copia qui le foto, es. `images/anello-fucsia.jpg`.
2. In `collezione.html` e `index.html`, dentro ogni `<div class="card-swatch ...">`, sostituisci il tag `<svg>...</svg>` con `<img src="images/anello-fucsia.jpg" alt="Anello fucsia">`.
3. Consiglio: foto quadrate, almeno 800x800px, sfondo chiaro o neutro per uniformità.
